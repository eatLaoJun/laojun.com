# 房间工作台

## 当前房间

- 房间外框横向约 6.25 米、纵向约 4 米，合计约 25 平方米，包含卫生间。
- 卫生间横向约 2.25 米、纵向约 2.75 米，约 6.19 平方米，靠入户门所在的角落。
- 平面图暂以右侧为入口、左侧为窗，窗和门在两侧墙上但不对齐。左墙窗沿墙向下错开，窗宽暂按原示意的两倍画为 2.20 米。卫生间位于入户一侧的右下角。
- 过道由卫生间隔墙和外墙围出，入户门居中过道端头，卫生间门位于侧面的隔墙上并通向过道。虚线只表示过道进入主房间的开放端，不是一堵墙。
- 左右方位、门窗开口宽度及偏移、卫生间门沿过道墙的偏移和开启方向、墙厚和层高待实测。当前家具只是试摆，不代表家里的现有家具。
- 房间数据以厘米记录，`x` 向右、`z` 向下，2D 和 3D 共用 [`src/room/model.ts`](../src/room/model.ts) 的几何定义。卫生间是独立区域，卧室家具只能摆在它外面。

## 视角操作

3D 画布左上的左右按钮从当前视角转动 45°。自由旋转仍然用右键拖动，手机可拖动空白处旋转。转向不会改动家具位置或缩放比例。

## 后续 Agent 需求：按描述新增房间

用户可以说：「帮我新建一个 6.25 米宽、4 米深的房间，右侧是入户门，左侧有一扇 2.20 米宽的窗，和入户门错开。靠入口隔出 2.25 × 2.75 米的卫生间。卫生间和外墙之间留过道，入户门居中开在过道端头，卫生间门通向过道。」

1. Agent 把描述转成结构化房间草稿：外框尺寸、开口所在的墙、隔间尺寸和相对位置。没有明确的信息（比如门左还是门右）要追问，或标成可修改的暂定值，不能当成实测。
2. 程序校验尺寸、隔间边界和门窗开口，再用同一份数据生成 2D 和 3D 预览。
3. 用户确认后才新增房间；新建不覆盖当前房间及其家具布局。

当前只实现固定房间和手动摆放，不接 Agent，也没有多房间管理。
